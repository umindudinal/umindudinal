### 🦁 GuideLanka — AI Safari Tourism Platform
> *Group project | Supervisor: Dr. Kalpana Galappaththi | ITUM 2025–2026*

An intelligent multi-platform tourism system for **Yala National Park (Blocks 5 & 6)**, connecting tourists, drivers, and park authorities in real time.

| Layer | Tech |
|---|---|
| 🌐 Tourist Web App | React + Vite, dark forest/earthy UI |
| 📱 Driver Mobile App | Flutter (Dart) — full end-to-end, release APK shipped |
| 📊 Authority Dashboard | React |
| 🔗 REST API | Node.js |
| 🗄️ Database | Supabase (PostgreSQL) |
| 🗺️ Maps | Mapbox GL |
| 🤖 AI | Gemini AI integration |
| 🔔 Notifications | Firebase Cloud Messaging (FCM) |

**Custom S2R Algorithm:**
```
RSn = Sr × 0.5 − Cd × 0.3 − Dist × 0.2
```
*Sighting-to-Route scoring — ranks driver routes dynamically based on wildlife sighting reports, crowd density, and distance.*

`#React` `#Flutter` `#Node.js` `#Supabase` `#Mapbox` `#GeminiAI` `#Firebase` `#PostgreSQL`
