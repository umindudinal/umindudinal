### 🦁 GuideLanka
AI-based safari tourism platform for Yala National Park — five-member capstone project, final viva submitted.

Core of the system is a custom **Sighting-to-Route (S2R)** scoring formula that ranks driver routes in real time:

`RSn = Sr × 0.5 − Cd × 0.3 − Dist × 0.2`

- Tourist Web App — React, Supabase, Mapbox
- Safari Driver App — Flutter, full layered architecture, shipped APK
- Park authority live-tracking dashboard
- Complete SRS documentation + final presentation
